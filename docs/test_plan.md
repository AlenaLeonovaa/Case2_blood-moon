Тест-план проекта Кровавая Луна

1. Общая информация
Цель: проверить игровую логику, корректность расчёта ресурсов и стабильность hot-seat режима на 4 игроков.
Методы: юнит-тесты (pytest), ручное тестирование, автотест на вероятность.
Файлы: tests/test_logic.py, docs/test_plan.md, docs/bug_reports.md.

2. Таблица тест-кейсов

| # | Что проверяем | Метод | Ожидаемый результат |
|---|---------------|-------|--------------------|
| T1 | Стартовые ресурсы | Запуск | 10/10/5/10/0 |
| T2 | Формула престижа | Юнит-тест | land*2 + money//5 + people//5 - smuta |
| T3 | Смерть при смуте = 10 | Юнит-тест | is_dead == True |
| T4 | Смерть при народе = 0 | Юнит-тест | is_dead == True |
| T5 | Событие срабатывает 1 раз за ход | Ручной | В логе 1 событие на ход |
| T6 | Действие требует ресурсы | Ручной | Кнопка серая при нехватке |
| T7 | Смена игрока после действия | Ручной | Ход переходит 1→2→3→4→1 |
| T8 | Вероятность позитив/негатив ~50/50 | Автотест на 10000 итераций | Отклонение < 3% |
| T9 | Победа при престиже ≥ 30 | Юнит-тест | game_over, победитель определён |
| T10 | Кнопки реагируют на hover | Ручной | Цвет меняется |

3. Автотесты (pytest)

Файл tests/test_logic.py содержит 11 тестов:

| Тест | Что проверяет | Ожидание |
|------|---------------|----------|
| test_player_initialization | Стартовые ресурсы | 10/10/5/10/0 |
| test_prestige_formula | Формула престижа | 5*2 + 10//5 + 10//5 - 0 = 14 |
| test_death_by_smuta | Смерть при смуте 10 | is_dead == True |
| test_death_by_people | Смерть при народе 0 | is_dead == True |
| test_can_afford | Хватает ли ресурсов | True при 5 ≥ 3, False при 5 < 10 |
| test_action_alliance | Союз: −1 смута обоим, не ниже 0 | smuta 5→4, 0→0 |
| test_action_trade | Торговля: −3 деньги, +3 еда | money 10→7, food 5→8 |
| test_action_raid | Набег: −1 народ, −2 еда цели, +1 смута | 10→9, 10→8, 0→1 |
| test_action_bribe | Подкуп: −3 деньги, −2 смуты цели | money 10→7, smuta 5→3 |
| test_action_discord | Раздор: −2 деньги, +2 смуты цели | money 10→8, smuta 2→4 |
| test_roll_event_distribution | Вероятность ~50/50 | 400 < positives < 600 из 1000 |

4. Чек-лист ручного тестирования

- Игра запускается на Windows/Linux.
- Окно 1280×720, закрывается по крестику.
- 4 игрока отображаются своими цветами.
- Модалка события блокирует клики.
- После 4 ходов снова ход игрока 1.
- Смута не уходит в минус.
- Лог хранит последние 5 записей.
- Игра завершается при победе/поражении.
- Кнопки становятся серыми при нехватке ресурсов.
- Кнопки меняют цвет при наведении (hover).
- Музыка играет в меню.
- Музыка переключается на игровую при старте.
- Музыка меняется на победную при выигрыше.
- Звук не прерывается, не глючит, не накладывается друг на друга.

5. Критерии успеха
Все 11 юнит-тестов зелёные (python -m pytest tests/).
Игра запускается без ошибок.
Все пункты чек-листа пройдены.
Найденные баги оформлены в docs/bug_reports.md.
