# Критерии 

## Общие
- [ ] Игра запускается командой `python main.py`
- [ ] Окно 1280×720, закрывается по крестику
- [ ] Работает на Windows и Linux
- [ ] Нет ошибок в консоли при запуске

## Игровой процесс
- [ ] Hot-seat на 4 игроков, ход переходит 1→2→3→4→1
- [ ] Все 5 действий реализованы и работают
- [ ] Все 6 событий реализованы
- [ ] Событие срабатывает 1 раз за ход
- [ ] Событие показывается модалкой с кнопкой «Продолжить»
- [ ] Кнопки действий неактивны при нехватке ресурсов
- [ ] Hover на кнопке меняет цвет

## Отображение
- [ ] Панель ресурсов показывает: пропитание, деньги, землю, народ, смуту
- [ ] Престиж отображается и пересчитывается
- [ ] Лог хранит последние 5 сообщений
- [ ] Каждая фракция отображается своим цветом

## Победа / поражение
- [ ] Победа при престиже ≥ 30
- [ ] Победа последнего выжившего
- [ ] Победа по престижу после 20 ходов
- [ ] Выбывание при смуте ≥ 10
- [ ] Выбывание при народе ≤ 0

## Тесты
- [ ] `pytest tests/` — все тесты зелёные
- [ ] Формула престижа работает верно
- [ ] Распределение событий ~50/50

## Документация
- [ ] В репозитории есть `docs/` с артефактами всех ролей
- [ ] README содержит инструкцию запуска
- [ ] requirements.txt актуален
