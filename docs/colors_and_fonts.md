## 5. UX-правила

1. **Неактивная кнопка** — цвет `disabled`, не кликается, если у игрока не хватает ресурсов на действие.
2. **Hover** — при наведении мыши кнопка меняет `button` → `button_hover`.
3. **Модалка события** — затемняет фон (чёрный с прозрачностью 60%), блокирует клики по остальным элементам.
4. **Смена хода** — задержка 1.5 секунды после действия.
5. **Лог** — хранит только последние 5 сообщений.
6. **Опасные значения** — при `smuta >= 7` число краснеет (`negative`); при `people <= 3` — тоже.
7. **Положительные эффекты** в логе — цвет `positive`, отрицательные — `negative`.
8. **Смена хода** — полоска под header меняет цвет на цвет следующего игрока.

## 6. Логика отрисовки ресурсов

В панели ресурсов отображаются 6 значений в ряд:

| Иконка (файл) | Подпись | Поле в Player |
|---|---|---|
| `icon_food.png` | Пропитание | `food` |
| `icon_money.png` | Деньги | `money` |
| `icon_land.png` | Земля | `land` |
| `icon_people.png` | Народ | `people` |
| `icon_smuta.png` | Смута | `smuta` |
| `icon_prestige.png` | Престиж | `prestige` |

Порядок иконок слева направо фиксирован.
