# Кровавая Луна

Пошаговая стратегия на Python и Pygame.

В игре четыре фракции сражаются за выживание под Кровавой Луной:

- Вампиры
- Оборотни
- Ведьмы
- Охотники

Игроки управляют ресурсами, переживают случайные события, заключают временные союзы и взаимодействуют с другими фракциями.

## Игровой процесс

Каждый ход состоит из двух этапов:

1. Случайное событие:
   - изменяет ресурсы игрока;
   - может быть положительным или отрицательным.

2. Действие игрока:
   - Союз;
   - Торговля;
   - Набег;
   - Подкуп;
   - Раздор.

Цель игры:

- набрать 30 очков престижа;
- остаться последней выжившей фракцией;
- иметь максимальный престиж после 20 ходов.

## Ресурсы

В игре используются:

- Пропитание — основной ресурс фракции.
- Деньги — используются для действий.
- Земля — влияет на доход.
- Народ — сила фракции.
- Смута — показатель нестабильности. При достижении 10 игрок выбывает.

## Технологии

- Python 3.10+
- Pygame 2.5+
- pytest
